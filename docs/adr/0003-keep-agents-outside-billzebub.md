# Keep conversational agents outside Billzebub

Billzebub will expose financial queries, review queues, and explicit mutation operations through a secured, versioned REST JSON API, with a stateless local stdio MCP adapter for personal agents, rather than embedding an agent runtime, chat interface, or categorization model. Agent-safe resources contain only opaque Transaction IDs, Counterparty, amount and currency, effective date, Transaction kind, Category, and review choices; scoped, revocable tokens and idempotent, concurrency-checked mutations let agents assign obvious Categories, create Pending Reviews, and propose Corrections or Reconciliation without exposing account identifiers, Claims, Source Artifacts, raw descriptions, or audit internals. This keeps ingestion and ledger behavior deterministic, lets users choose their own agent, model, and messaging channel, and prevents agent framework choices from becoming part of the financial system's core.
